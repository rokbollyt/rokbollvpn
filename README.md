# Rokboll VPN — как это работает

Простое объяснение, без кода. Техническая карта проекта — в `ARCHITECTURE.md`.

---

## Идея в двух словах

Обычный VPN легко заметить: провайдер видит незнакомый шифрованный поток на
незнакомый адрес и может его срезать. Здесь подход другой — трафик прячется
внутри того, что блокировать не станут:

- **MAX-TURN** — трафик идёт через настоящие серверы видеозвонков мессенджера
  MAX (это инфраструктура VK/OK). Снаружи выглядит как обычный видеозвонок.
- **Minewire** — трафик маскируется под подключение к серверу Minecraft.

В приложении оба варианта — просто «серверы» в списке: выбрал и подключился.

---

## Что происходит, когда ты нажимаешь «ON»

Вариант MAX-TURN (основной):

1. Приложение логинится в звонковый сервис MAX по встроенной сессии.
2. Получает адрес TURN-сервера MAX и одноразовый логин/пароль к нему.
3. Поднимает шифрованный канал (DTLS) через этот TURN-сервер до нашего VPS.
4. На VPS канал расшифровывается и трафик уходит в интернет.
5. На твоём компьютере появляется сетевой адаптер, и весь трафик системы
   (браузер, игры, программы) идёт через этот канал.

Путь трафика:

```
твой ПК → TURN-сервер MAX (видеозвонки) → наш VPS → интернет
```

Для провайдера это трафик видеозвонка на IP-адреса VK. Наш сервер он не видит.

Вариант Minewire работает так же, но вместо звонков маскируется под Minecraft:

```
твой ПК → наш VPS (притворяется сервером Minecraft) → интернет
```

---

## Как этим пользоваться

1. Запусти `minewire-gui.exe`. Windows спросит права администратора — нужно
   согласиться, без них нельзя создать сетевой адаптер.
2. Откроется окно приложения. Никаких кодов и сессий вводить не нужно —
   наши серверы и сессия MAX уже встроены в программу.
3. Нажми большую кнопку **ON**. Через 10–20 секунд статус станет «ПОДКЛЮЧЕНО».
4. Проверь на сайте вроде ifconfig.co — должен показаться IP нашего сервера.
5. Чтобы отключиться — нажми ту же кнопку (она станет **OFF**).

## Что есть в настройках

- **Автовыбор сервера** — при подключении сам проверит все серверы и выберет
  тот, у которого меньше задержка (пинг).
- **Автоподключение при запуске** — включает VPN сразу при старте программы.
- **Исключить программы** — выбранные программы пойдут напрямую, минуя VPN
  (удобно для банков, госуслуг, торрентов).
- **Логи приложения** — скопировать логи, если что-то не работает.
- **Выбор сервера** — нажми на строку с флагом, чтобы сменить сервер или
  добавить свой собственный.

Красная кнопка «ВЫХОД ИЗ ПРИЛОЖЕНИЯ» полностью закрывает программу и
восстанавливает обычную сеть.

## Из чего состоит проект

| Часть | Где живёт | Зачем |
|---|---|---|
| Приложение для Windows | у тебя на ПК | окно, кнопка, настройки, сам туннель |
| Наш VPS `rokboll.xyz` | сервер в Финляндии | принимает трафик и выпускает в интернет |
| Бэкенд на Cloudflare | Cloudflare Worker | выдача ключей по коду приглашения (сейчас выключено) |
| Телеграм-бот админки | внутри бэкенда | генерация кодов, управление серверами и сессией MAX |

Сейчас приложение работает в режиме «всё встроено»: коды приглашений и
бэкенд не используются, серверы и сессия MAX зашиты внутрь программы.
Система кодов при этом уже написана и развёрнута — её можно включить обратно
в любой момент.

---

## Что нужно знать заранее

- **Сессия MAX со временем истекает.** Тогда MAX-TURN перестанет подключаться,
  и нужно будет обновить сессию в программе (или включить обратно бэкенд, чтобы
  обновлять её централизованно через телеграм-бота).
- **Один канал на одну сессию.** Мы специально не открываем много соединений,
  чтобы аккаунт MAX не забанили за поведение, похожее на бота.
- **Нужны права администратора.** Без них Windows не даст создать сетевой
  адаптер, и VPN не включится.
- **Если что-то сломалось на уровне сети** — в приложении есть аварийный сброс,
  который удаляет маршруты и возвращает интернет в обычное состояние.

---

## Куда смотреть, если не работает

1. Статус остался «ОТКЛЮЧЕНО» → открой настройки, скопируй логи, там будет
   причина (чаще всего: истёкшая сессия MAX или недоступный сервер).
2. Интернет пропал совсем → нажми «ВЫХОД ИЗ ПРИЛОЖЕНИЯ», сеть восстановится.
3. Подключилось, но сайты не открываются → проверь, что выбранный сервер
   доступен: включи «Автовыбор сервера» и подключись заново.
